# Protocol Converter

充电通信协议 CAN 报文工具：**协议查询、帧解码、批量抓包解析**。本地运行，浏览器访问，不需要安装客户端。

支持 GB/T 27930-2023、国网三统一 V107、英飞源 V107、安世博 UAA-1K040B-E 四种协议。

---

## 快速开始

### 方式一：直接运行（推荐）

1. 解压 `ProtocolConverter_vX.X.X.zip`
2. 双击目录里的 `ProtocolConverter.exe`
3. 浏览器会自动打开 `http://127.0.0.1:8027`

关闭程序：关掉黑色命令行窗口即可。

### 方式二：源码运行

```bash
pip install -r requirements.txt
python main.py
```

需要 Python 3.10+。

## 三个功能

### 1. 协议查询

顶部下拉框选协议，左侧是报文树，点任意一条查看字段定义。

右侧详情里可以直接改字段值，点「编码」得到 CAN ID 和数据域，适合手工拼帧。

> 顶部有 🔄 GitHub / 🔄 Gitee 两个按钮，用于检查新版本。只下载更新包，不会自动替换程序。

### 2. 帧解码

填两样东西：

| 输入 | 格式 |
|------|------|
| CAN ID | `18019FA0` 或 `0x18019FA0` |
| 数据域 | `01 02 07 00 00 04 88 0D`（空格分隔，可省略 `0x`） |

点「解码」，会给出 CAN ID 各位域的含义和数据域每个字段的值。

### 3. 批量解析

支持 `.xlsx`、`.csv`、`.tsv` 以及固定宽度的文本抓包。

1. 拖入文件，或点「输入路径」（适合文件很大或路径很深的情况）
2. 确认「帧 ID 列」和「数据列」的映射，一般会自动识别
3. 点「开始解析」
4. 结果可翻页查看，也可「导出 Excel」

多帧报文（27930 的 TP 传输、三统一的定值帧）会自动重组后解析，不需要手工拼。

## 支持的协议

| 协议 | 标识方式 | 报文数 |
|------|---------|--------|
| GB/T 27930-2023（A 类系统） | PF | 22 |
| 国网三统一 V107 | PF | 31 |
| 英飞源 V107 | 命令号（含请求/回复） | 32 |
| 安世博 UAA-1K040B-E | 数据域命令类型 | 60 |

## 使用小贴士

- **CAN ID 前缀随意**：`0x18019FA0` 和 `18019FA0` 都能识别。
- **数据域可以有空格、也可以没有**：`01 02 07` 与 `010207` 等价。
- **27930 的 TP 多帧**：单帧解码时贴出其中任意一帧即可匹配到报文；批量解析会按 RTS 自动归组后重组。
- **三统一定值帧**：协议用自定义序号分帧（不是 J1939 TP），工具已适配，直接解析即可。
- **英飞源请求与回复同命令号**：工具按源地址判断方向，请求显示「监控→模块」，回复显示「模块→监控」。
- **消息树的标识列**：27930 显示 PF（如 `0x26`），英飞源显示命令号（如 `CMD8`），安世博显示命令类型（如 `0x00`）。

## 常见问题

**浏览器没自动打开？**
手动访问 `http://127.0.0.1:8027`。若提示端口被占用，说明已有一个实例在运行，先关掉它。

**上传文件时报「无法识别文件格式」？**
确认文件是 xlsx / csv / 定宽文本之一。CSV 需要至少有「帧 ID」和「数据」两列。

**解析结果全是 UNKNOWN？**
先看「协议」是否选对。四种协议互不兼容，选错会让所有帧都匹配不上。

**文件打不开，提示权限错误？**
如果是 Windows EFS 加密目录下的文件，用「输入路径」方式加载，程序会用系统命令复制一份再读。

**检查更新提示有新版本，怎么升级？**
点下载后，更新包会保存到 `下载` 文件夹。关闭程序，用新包覆盖旧目录，重新启动即可。

**从仓库克隆下来，为什么只有 27930 一个协议？**
厂家私有协议（三统一、英飞源、安世博）的定义文件不随仓库公开。自行获取后放入 `data/` 目录即可，文件名需为 `sg_unified_v107.json`、`infypower_v107.json`、`anshibo_1k040b.json`。
